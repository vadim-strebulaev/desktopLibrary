# 📚 Цифровая Библиотека

Desktop-приложение на Python + PyQt6 с базой данных SQLite3, симулирующее работу цифровой библиотеки.

## Возможности

- **Читатели:** регистрация и авторизация, просмотр каталога, взятие книг, возврат, очередь, отзывы и оценки
- **Администратор:** управление каталогом (добавление / редактирование / удаление книг), просмотр пользователей и всех заявок
- **Фильтры и сортировка:** по жанру, автору, доступности, рейтингу, году, названию
- **Рекомендации:** топ-5 самых читаемых книг

## Стек технологий

| Компонент  | Технология      |
|------------|-----------------|
| Язык       | Python 3.10+    |
| GUI        | PyQt6           |
| БД         | SQLite3 (встроен в Python) |
| ОС         | Windows / Linux |

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/vadim-strebulaev/desktopLibrary.git
cd desktopLibrary

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить приложение
python main.py
```

При первом запуске автоматически создаётся файл базы данных `library.db` и добавляется аккаунт администратора:

| Логин | Пароль |
|-------|--------|
| admin | admin  |

## Структура проекта

```
desktopLibrary/
├── main.py           # Точка входа
├── database.py       # Работа с SQLite3
├── login_window.py   # Окно входа и регистрации
├── main_window.py    # Главное окно читателя (каталог, мои книги, рекомендации)
├── admin_window.py   # Панель администратора
├── requirements.txt
└── README.md
```

## Схема БД

- **users** — пользователи (ФИО, логин, пароль, номер билета, роль)
- **books** — книги (название, автор, год, жанр, доступность)
- **requests** — заявки (кто взял какую книгу, статус)
- **queue** — очередь на занятые книги
- **reviews** — отзывы и оценки (1–5)
