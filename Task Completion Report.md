## 1. Введение

Целью данной работы является разработка desktop-приложения «Цифровая библиотека», предназначенного для управления книгами, пользователями и процессом выдачи книг.

Приложение разработано на языке Python с использованием библиотеки PyQt6. В качестве базы данных используется SQLite.

---

## 2. Функциональные требования

### 2.1 Управление каталогом книг

Реализованы следующие возможности:
- добавление книг
- редактирование книг
- удаление книг

Каждая книга содержит:
- ID
- название
- автора
- год выпуска
- жанр
- статус (доступна / занята)

---

### 2.2 Регистрация и авторизация

Пользователь может:
- зарегистрироваться (ФИО, логин, пароль)
- войти в систему

---

### 2.3 Работа с книгами

- пользователь может взять книгу
- если книга занята — пользователь добавляется в очередь
- при возврате книга передаётся следующему пользователю

---

## 3. Расширенный функционал

Реализованы дополнительные функции:
- отзывы на книги
- оценки (от 1 до 5)
- расчет рейтинга книг
- рекомендации (топ-5 популярных книг)
- фильтрация каталога

---

## 4. Используемые технологии

- Python
- PyQt6
- SQLite3
